# Mend release notes

Newest first. Downloads: https://github.com/JKS-sys/mend-08-oct-2026-releases/releases/latest · https://ipconfig.co.network/mend

## Mend 1.0.29 — 09 Nov 2026

- **Saving to iCloud no longer fails with "invalid args book".** The list of contact sources is rebuilt now and then, and a rebuilt iCloud source that wasn't loaded again had lost which address book to save into. Merging, fixing or copying into it then failed. Mend now remembers each account's address book, and looks it up again if needed.
- **Merge all no longer stops every 100 people.** Every merge is worked out first; then they're saved 100 at a time. A batch that fails is retried once and then set aside, and the next batch still runs. The summary says how many were merged and how many couldn't be saved and why, and Resume tries those again.

## Mend 1.0.28 — 09 Nov 2026

- **Merge all in a library book no longer loses or mixes up cards.** A book holding the same card id twice (contacts copied in twice, or an export from another app) gave those cards one shared key, so merging, saving or deleting one changed or removed the others too. Every card now gets its own key; a repeated id is given a new one, and a new card never takes an id the book already has.
- **A library book that can't be saved says so.** The write is tried again three times. If it still fails, Mend tells you, your changes stay in memory while it's open, and the error goes to the error reports. Before, the failure was silent.
- **Merge all can be resumed.** It merges 100 people at a time and saves each batch before the next. If it stops, from an error, a lost connection or a quit, the merged ones are kept, and **Resume** (with a progress bar) merges what is left.
- **Resume after quitting.** An unfinished copy, move or Merge all is remembered after you quit. At the next start Mend says what wasn't finished and where to resume; anything already done is skipped. Fix all and Delete pick up where they stopped just by running them again.
- **AI tidy never cuts a note.** A note is summarised into as many short lines as its facts need, every number, date, amount and name kept. The whole note is sent (a very long one on its own), the answer has room for all of it, and every contact is tidied (before, only the first 600).
- **`update.sh --appstore` finds the provisioning profile by itself.** When `.env` has none, or one that doesn't read, it looks in Downloads, Desktop, the project folder and Xcode's profiles folders. It takes the newest Mac App Store profile for Mend's App Store bundle id and this Mac's Apple Distribution certificate, and saves it into `.env`, so `vault.mjs push` carries it to other Macs.
- **App Store uploads fall back to the Apple ID.** When the App Store Connect API key's .p8 file isn't on this Mac, the upload uses the Apple ID and app-specific password instead of stopping.

## Mend 1.0.26 — 08 Nov 2026

- **Finder → Services reach the Mend you use.** Finder sends Services to whichever Mend.app macOS knows about, and a copy left in a build or download folder could catch the click and do nothing. Mend now registers itself as the one that answers, once per version, and refreshes the Services menu. The release script also makes macOS forget its build copies.
- **New Finder service: Remove Duplicates with Mend.** Right-click a folder or disk → Services → Remove Duplicates with Mend. Mend scans it, keeps one file in each group (by your Keep rule, never the last copy), and asks once before moving the extra copies to the Trash. Find Duplicates with Mend still only shows them.
- **Deleting contacts no longer fills the library.** A copy in the Mend library is made only when you tick **Keep a copy in the library** in the Select bar; otherwise deleted contacts are simply gone, and the confirmation says so.
- **Copying to iCloud can be resumed, and no longer stops on one bad card.** A busy server or a dropped connection (429, 5xx, time-outs) is retried three times, slower each time. A contact that still won't go is set aside while the rest carry on. Accounts take four contacts at a time. An unfinished copy or move is remembered, even after quitting, and Copy & move shows **Resume**. Resuming skips every contact already in iCloud (same card id), so nothing is doubled. The summary says how many arrived, how many were already there, and how many didn't go and why.

- **Duplicates are cards that share a mobile number, and nothing else.** A matching name, a shared email, a shared office line, a fax or a pager no longer makes two cards one person. Whether a number is a mobile comes from its label (mobile, cell, iPhone), or else from Google's numbering rules.

## Mend 1.0.22 — 07 Nov 2026

- **Every number gets its own country code, and Mend no longer asks for yours.** For a number written without a code, Mend looks at the contact first: their other numbers written with +, their address, their email's country domain. A number that is real there gets that country's code, so a UK contact's number becomes +44 even when it would also pass as Indian. Only when the contact points nowhere does Mend use this Mac's own country (from its Region setting). A number that is real in none of these is left exactly as written. Each fix says where its country came from. The "Your country code" box and the country code choice are gone from Fix and Numbers.

## Mend 1.0.21 — 07 Nov 2026

- **Put another Mac in DFU from this one.** Other Mac now has **Put it in DFU for me**: connect a USB-C cable between both Macs' DFU ports, press the button, and the other Apple silicon Mac restarts straight into DFU, ready for Revive or Restore. No keys to hold, and nothing on it changes. It uses macvdmtool, which Mend builds the first time in about a minute (Install the DFU helper); it asks for your administrator password. The key combination is still there as the way by hand.
- **A tiny backup of the whole Mac.** Tiny Backups has **This whole Mac**, which backs up your home folder: documents, settings, mail, messages, the photos library and app data, every repeated piece stored once and compressed. Caches, the Trash, build leftovers (node_modules, Xcode's), iPhone backups and Mend's own backups are left out. Next to the backup, a list of your apps (with versions, and whether they came from the App Store) and your macOS version is saved, to reinstall after a clean macOS. The apps themselves aren't copied.
- **Merging duplicate contacts loses nothing.** The first card's name is the one shown, and every other name becomes a nickname, so search still finds "Ravi K" and "Ravi". Every phone number, email, address, website and profile is kept, even the same number written another way or with another label; only exact copies are left out. The note lists each card, one below the other, with everything it had, including a second company or birthday that didn't fit the field. A merged note is never trimmed, and Fix all no longer shortens any note. A blank number on one card is no longer copied into the merged one.
- **iPhone backup and restore check the phone first.** "Could not start service com.apple.mobilebackup2: Invalid service" means the iPhone wasn't ready: it hadn't finished its first setup (after an erase or a Deep Repair), or it didn't trust this Mac. Backup and Restore now check both before they start. If the phone needs to trust the Mac, Mend asks it to; otherwise it says exactly what to do on the phone (go through setup until Transfer Your Apps & Data → From Mac or PC; or unlock and tap Trust). "What to try next" says the same.
- **Errors reach the dashboard, so they get fixed.** A repair that doesn't finish is sent to the ipconfig dashboard's Crashes & errors, grouped by what went wrong: the repair, its first error line and the end of its log, with the Mend version and macOS version. This happens only when Settings → Privacy allows (the same switch as the daily ping), each kind of error once per session and at most 40. Names, home folders, device ids, serial numbers, ECIDs, emails, phone numbers and IP addresses are taken out first. Sends that fail while offline go with the next start.

## Mend 1.0.19 — 06 Nov 2026

- **Fix all problems no longer closes Mend.** On a big contact list, each fixed contact was saved on its own and the whole list was checked again after every one, thousands of times over, until the window froze and macOS closed it. Mend now works out every fix first and saves them together, with one redraw at the end.
- **The Fix button counts problems, not contacts.** It says, for example, "Fix all 1,240 problems in 812 contacts", because one contact can have several problems. Problems Mend can't fix by itself are counted separately.
- **Country codes your way.** Contacts → Fix has a choice for numbers written without a country code: **Find each contact's country**, the new default, keeps a number with your code when it is a real number in your country; otherwise it uses the country the contact's other numbers, address or email point to, and says which. **Use my country code** gives every such number your code. **Don't add country codes** leaves every number exactly as written. Mend remembers the choice.

## Mend 1.0.18 — 06 Nov 2026

- **An iPhone backup's contacts go into the library in one click.** A read-only source (an iPhone backup) now shows **Make an editable copy**, which copies every contact, field, photo and group into a new Mend library book and opens it, ready to edit and fix. Copy & move can also copy into a new library book, even when there is no account or book yet (before, it said to add one first and offered no way to).

## Mend 1.0.16 — 06 Nov 2026

- **Installing the newest iPhone tools works again.** The build stopped with "Package 'libcurl' not found": macOS has libcurl and zlib built in but no pkg-config files for them, so Mend now points the build at the Mac's own copies. Nothing extra to install.

- **No more copying `.env` to a new Mac.** Every key for building and releasing Mend lives in the ipconfig dashboard's vault. `bash update.sh` fetches them and saves new signing keys back. On a Mac signed in to GitHub (`gh`) there is nothing to do; otherwise run `node scripts/vault.mjs login` once and approve the six-letter code in the owner panel (Vault → Macs); the Mac keeps its own read-only key in the Keychain — nothing to type or copy.

Every value says where it came from, and estimates are marked as estimates. Detailed health needs smartmontools (`pour install smartmontools`). The disk report includes all of it.
- **Much faster to open and use.** The first screen loads about a third of the code it used to (149 KB instead of 461 KB compressed); every other page, the dialogs and the Fix Library load when first needed, and are warmed in the background a few seconds after start. The window asks for everything it needs at start-up in one call, saved settings are written in batches, background timers pause while the window is hidden, and sounds and pictures load after the window appears.
- **Log boxes come alive.** Each line gets a small drawn icon for its kind (step, command, done, warning, error, network, disk, phone, AI, backup, contact, firmware); the header shows a turning gear while a job runs, a check burst when it finishes and a crack when it fails; the progress bar shimmers over a stage strip; a live lines-per-second graph; pinned errors pulse; and a finished run ends with a summary card of time, steps, warnings and errors. Opening, finishing, failing, warnings, copying, saving, filtering, jumping and pinning each have their own sound.
- **64 new sounds, each with its own drawn animation** (270 in all), for iPhone restore, firmware download and checks, DFU and recovery, First Aid, partition, erase, APFS, RAID, disk images, backups, contacts, AI, Wi-Fi and USB, battery, updates, sign-in and more. - **More colour, never pink.** Six new colours (15 in all), every one readable in both themes. Dates, ages, durations, sizes, data written, percentages, temperatures, versions, serials, model names, e-mail addresses and phone numbers each get their own colour; brackets are coloured by depth in seven colours, with a wavy line under a bracket that has no partner; code in AI answers is fully coloured. Every page, section, tab, table header, badge and menu has its own colour, and the same meaning always has the same colour (disks amber, phones cyan, contacts teal, backups green, AI violet, errors red, warnings orange).
- **Mend now runs only on Macs with Apple silicon.** Intel, Windows, Linux, ChromeOS and FreeBSD builds stopped (their older installers stay on the releases page). Mend still repairs iPhones, Android phones and Windows or Linux disks plugged into the Mac.

Because the signature moves once to the Developer ID, macOS asks for Mend's permissions (Contacts, removable volumes, folders, Full Disk Access) one more time after this update, then keeps them.
- **Mend for the Mac App Store** (being prepared for review). It is sandboxed, sells Mend Pro Monthly (₹4,000) and Yearly (₹6,000) through the App Store and links the purchase to your Mend account, so the website version gets Pro too. Restore purchases is in the Mend Pro window. Features the App Sandbox does not allow show a notice with a link to the full Mend.
- **Free fixes now have a daily limit.** Without Mend Pro, a computer gets 3 fixes a day. Looking, scanning, device info, disk health and diagnosing stay free and unlimited. A fix counts only when it works: a failed or stopped fix is given back. Each fix frees up again 24 hours after it ran. After each free fix Mend says how many are left today; when they run out, the Mend Pro window explains when the next one frees up. Pro and the owner's Mac are never counted.
- **Mend's server keeps its records in the ipconfig dashboard.** Activation codes and subscription links live in Mend's own dashboard database (`mend-08-oct-2026`); purchase claims and the sync stamp live in the dashboard's key-value store (`mend-kv-08-oct-2026`). - **Menu, Dock, Finder and notification commands always reach their page**, even right after launch while that page is still loading (they used to be lost on a cold start). Settings changed just before quitting are kept.
- **A code can never be activated on two computers at once, and a cancelled code stays cancelled**: the server always reads codes fresh. Only subscriptions bought for Mend can turn on Mend Pro.
- **A database that cannot answer is now reported as an error**, never as "this code doesn't exist", so a busy server can never switch off someone's Pro or overwrite a code.

### Install

- **macOS on Apple silicon** (M1 and newer): `curl -fsSL https://ipconfig.co.network/pour/install | sh` then `pour install --cask mend`

First launch on macOS after a manual DMG install: `xattr -cr /Applications/Mend.app` (Mend is ad-hoc signed, not notarized).
